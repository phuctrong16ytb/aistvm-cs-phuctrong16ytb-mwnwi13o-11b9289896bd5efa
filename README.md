# AISTVM — Windows cloud tức thì

Kho này do AISTVM tạo tự động để chạy một máy Windows trong phiên làm việc của bạn.

- Máy chỉ tồn tại trong phiên hiện tại và tự dừng sau tối đa 12 giờ.
- Không lưu thông tin đăng nhập, mật khẩu hay khoá bí mật trong kho này.
- Bạn có thể xoá kho này sau khi phiên kết thúc.
